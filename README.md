# Amazon Stock Return Analysis

Statistical analysis of Amazon (AMZN) stock returns using Python to examine return behavior, distribution characteristics, and deviations from normality.

## Project Overview

This project analyzes historical Amazon stock price data and explores the statistical properties of stock returns. The analysis focuses on understanding return distributions and evaluating how closely empirical returns follow a theoretical normal distribution.

## Analysis

- Calculated daily simple returns from historical stock price data
- Computed descriptive statistics including mean, variance, and standard deviation
- Visualized return distributions using histograms
- Applied Kernel Density Estimation (KDE) to examine the empirical distribution
- Fitted a theoretical normal distribution to observed returns
- Used Q-Q plots to evaluate deviations from normality
- Examined patterns in historical stock returns using statistical visualization
